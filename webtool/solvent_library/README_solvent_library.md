# Solvent library of IsoScreen

Generated by `webtool/build/build_solvent_library.py` from the dataset in `data/`. No measured value is changed.

## Rules

- **Names.** Measured solvents keep the most frequent name in the dataset (`name_dataset`). Ionic liquids are named cation plus anion (`name`) and, where a systematic abbreviation exists, as [cation][anion] (`name_short`, for example [C4mim][BF4]).
- **Anions.** Names and abbreviations of all anions were set by hand.
- **Cations.** The full name is the most frequent form in the dataset names. Abbreviations follow the usual patterns ([CnCmim], [Cnpy], [Cnmpyr], [Cnmpip], [Cnmmor], [N1888], [P6,6,6,14] with commas when a chain has ten or more carbons), and functionalized cations were abbreviated by hand.
- **Combinations.** Cations and anions are combined into neutral salts. Duplicates are removed by the connectivity block of the InChIKey, so stereoisomers count as one solvent, and measured solvents take precedence.
- **Exclusions.** Ions containing Al, Co, Fe or Sb, which the GH-GNN featurizer cannot represent.
- **Applicability domain.** Highest Tanimoto similarity to all measured solvents except the solvent itself, from Morgan fingerprints (radius 2, 2048 bits, RDKit MorganGenerator) of the full solvent SMILES. With the non-test solvents of each fold as reference, the same calculation reproduces `validation/test_solvent_similarity_solvent_out.csv` for all 771 solvents.

## Sources and licences

- Measured solvents and ions: the dataset of this work.
- D. Prat et al., CHEM21 selection guide of classical- and less classical-solvents, *Green Chem.* 2016, 18, 288–296, doi:10.1039/C5GC01008J, CC BY-NC 3.0. Only solvent identities (names, and CAS numbers where given) were taken. SMILES were written from the names and checked with RDKit. Mixtures were not included.
- S. Langner, C. J. Brabec, List of organic solvents with information about Hansen solubility parameter, solvent properties, hazardousness and cost analysis, Mendeley Data V1, 2022, doi:10.17632/b4dmjzk8w6.1, CC BY 4.0. Only names, CAS numbers and SMILES were used.
- Identity check (`identity_check`): the SMILES of every added molecular solvent was compared with the structure for its CAS number or name in the `chemicals` package (MIT licence, PubChem data). 373 of 385 agree, 12 have CAS numbers outside the reference set and are kept as published, and none disagree. Diiodomethane from the Langner list cannot be represented by GH-GNN and was left out.

## Corrected structures

The library uses the corrected structures of eight measured solvents (`data/structure_corrections.csv`). Di-n-octyltin dichloride is therefore a molecular solvent, so the measured solvents comprise 457 molecular solvents and 310 ionic liquids. The cation table lists no metal fragments or duplicate charge placements, and the anion table lists hexafluoroantimonate and tetrabromocobaltate as single anions.
